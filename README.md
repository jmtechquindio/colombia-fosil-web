# COLOMBIA FÓSIL · Explorar para comprender

Sitio web de turismo geoarqueológico, divulgación científica y gobernanza comunitaria en Colombia.

## Características
- **Aplicación SPA sin dependencias de compilación** (HTML5, CSS3 con variables `oklch`, JavaScript ES Modules nativo y soporte de rutas profundas en GitHub Pages mediante `404.html`).
- **Catálogo de expediciones geoarqueológicas** organizado por tipología logística (planes cortos de 2–3 días y expediciones remotas de selva de 4–7 días) con narrativa orgánica, bloque estándar *Qué incluye*, cláusulas de transparencia en selva e impacto comunitario.
- **Adaptación del discurso** en tiempo real entre **Turista General / Explorador** y **Público Científico / Académico** (con referencias oficiales SGC e ICANH).
- **Catálogo documental de fósiles**, destinos territoriales y canal directo de atención por WhatsApp (`+57 322 625 0965`).
